# 当前风险与限制

- 真实账户流程尚未提交线上验收：本地已验证页面和门禁，但注册、邮箱验证码、找回密码和修改密码仍需使用真实账户手工确认。
- 线上发布清单仍是旧版本：Music 响应缺少 `display_version`，TV 与 AI 返回未配置；网站会分别显示“当前版本待确认”或“暂未提供下载”。
- `sjmf.xyz` 已完成首次部署；当前 HTTPS 证书通过手动 DNS TXT 验证签发，Certbot 未配置自动续期，证书到期前需要手动续期或接入 DNS API 自动续期。
- 网站前端门禁不能替代后端强制验证；当前后端受保护接口只校验 Bearer Session，后续如需严格禁止未验证邮箱账户访问业务 API，需要单独设计后端依赖和兼容策略。
- 现有原型 `prototype/assets/` 中仍保留两张未引用图片，正式构建不会打包它们；是否清理原型遗留文件需另行确认。
